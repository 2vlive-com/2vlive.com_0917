# แมนยู 2-3 ไบรท์ตัน: ผีนำสองตุงโดนรัวแซงคาบ้าน ตกรอบคาราบาว คัพ
แมนเชสเตอร์ ยูไนเต็ด ยังไม่สามารถเรียกความมั่นใจกลับมาได้ หลังเปิดรัง โอลด์ แทร็ฟฟอร์ด พ่าย ไบรท์ตัน แอนด์ โฮฟ อัลเบี้ยน 2-3 ทั้งที่ออกนำก่อนถึงสองประตู ส่งผลให้ “ปีศาจแดง” ตกรอบ 3 ศึก คาราบาว คัพ พร้อมกับแพ้เกมเหย้าเป็นนัดที่สองติดต่อกัน
ศึกคาราบาว คัพ รอบ 3 เมื่อวันพุธที่ 16 กันยายน แมนฯ ยูไนเต็ด ลงสนามด้วยความต้องการชัยชนะ หลังเพิ่งพบความพ่ายแพ้ในเกมแมนเชสเตอร์ ดาร์บี้ เมื่อสุดสัปดาห์ที่ผ่านมา
เจ้าถิ่นออกสตาร์ตได้อย่างยอดเยี่ยม และใช้เวลาเพียง 8 นาทีขึ้นนำ 1-0 จากความสามารถเฉพาะตัวของ เช เลซี่ย์ ดาวรุ่งที่แตะบอลหนีแนวรับ ไบรท์ตัน บริเวณกรอบเขตโทษ ก่อนซัดเต็มข้อส่งบอลเข้าประตู
เพียงสองนาทีต่อมา แมนฯ ยูไนเต็ด หนีเป็น 2-0 เมื่อ มาร์คัส แรชฟอร์ด ยิงไปติด เจสัน สตีล แต่บอลมาเข้าทาง เมสัน เมาท์ ที่ตามซ้ำด้วยการฟาดบอลกระดอนพื้นข้ามนายทวารทีมเยือนเข้าประตู
หลังเสียสองประตู ไบรท์ตัน ค่อยๆ ตั้งเกมได้และเริ่มสร้างแรงกดดันใส่เจ้าบ้าน กระทั่งช่วงทดเวลาครึ่งแรก จาเวน ฮัดฌาม วางบอลยาวให้ ชาราลัมปอส คอสตูลาส หลุดเข้าเขตโทษ ก่อนยิงลอดขา คาร์ล ดาร์โลว์ เข้าไปในนาที 45+1 ช่วยทีมเยือนไล่มาเป็น 1-2 ก่อนจบครึ่งแรกด้วยสกอร์ดังกล่าว
เข้าสู่ครึ่งหลัง ไบรท์ตัน เดินหน้าเปิดเกมรุก ขณะที่ แมนฯ ยูไนเต็ด มีโอกาสจากความผิดพลาดของ พาสคาล ชเตร้าค์ ที่ส่งบอลคืนหลังสั้น แต่ สตีล ยังออกมาตัดบอลได้ก่อน เบนยามิน เชชโก้ จะเข้าถึง
กระทั่งนาที 65 ไบรท์ตัน ตามตีเสมอ 2-2 หลังการเปิดบอลเข้ากลางของ ดีโอโก้ ดาโลต์ ถูกตัดได้ ก่อนบอลมาถึง ปาสกาล กรอสส์ ที่จัดการจบสกอร์ไม่พลาด
สถานการณ์ของ แมนฯ ยูไนเต็ด แย่ลงอีกในนาที 69 เมื่อทีมเยือนเล่นเกมสวนกลับ บอลมาถึง คอสตูลาส ที่ลากเข้าเขตโทษ ก่อนจ่ายให้ มักซิม เดอ ไคเปอร์ ยิงเข้าไป ส่ง ไบรท์ตัน พลิกแซงนำ 3-2
ช่วงเวลาที่เหลือ “ปีศาจแดง” ไม่สามารถทวงประตูคืนได้ ขณะที่ ไบรท์ตัน ยังมีโอกาสลุ้นเพิ่มอีกหลายครั้ง ก่อนจบเกมด้วยชัยชนะของทีมเยือน 3-2 ส่ง “นกนางนวล” ผ่านเข้าสู่รอบ 4 ส่วน แมนฯ ยูไนเต็ด ต้องยุติเส้นทางในคาราบาว คัพ เพียงรอบ 3
